# 704 腦力競賽｜數迴（slitherlink）流程與規則

版本：草案 v1｜日期：2026-11-25｜分支：`main`（原 `feature/slitherlink`）｜狀態：已整合主線，現場驗收待完成

依據：企劃書「數迴」列（5×5、共 3 關、每關 3 分鐘；第一次點擊畫線、第二次打叉、第三次回到空白）與範例題。題型參考 https://zh.puzzle-loop.com/ 的 5×5 簡單題；題目全部由程式自行生成並驗證，不抓取網站題目。

## 1. 玩家目標與教學

教學文案：「在點與點之間畫線，連成一條不交叉、不分岔的封閉迴圈；格子裡的數字代表這一格四邊有幾條線。」

- 盤面 5×5 格、6×6 個點、共 60 條邊。全員共用同一題；每位玩家在自己牆面上的作答各自獨立。
- 沒有數字的格子不限制線數。

## 2. 操作

- 點兩點之間的邊：第一下畫線 → 第二下打叉（表示確定沒有線）→ 第三下回到空白。
- 叉叉只是記號，不影響完成判定。
- 點在格子中央（數字處）、正好點在點上、或盤面外，都不會改變任何邊，避免誤觸。
- 沒有確認鍵：畫出的線與正解完全一致時自動完成並記錄耗時。答錯不鎖答、不扣分，可以隨時修改。

## 3. 流程、結束與計分

1. 大廳選擇（或隨機抽中）→ 遊戲介紹 → 教學 → 3 秒倒數。
2. 每關 180 秒，共 3 關。
3. 一般競速規則：N−1 人完成或時間到即結束；單人遊玩要等該玩家完成或時間到。
4. 依完成耗時排名，得 N−r 分；未完成者 0 分。
5. 小結算 5 秒：地板／題目區以金色顯示正解迴圈；每位玩家的牆面同時顯示自己的線，畫錯的線以紅色虛線標示。

## 4. 題目生成與驗證

1. 隨機長出一個連通、無洞、不在角落相接的格子區域；區域邊界就是一條簡單迴圈。
2. 算出所有格的數字，再依種子順序逐一隱藏數字；每隱藏一個數字，都重新用推理解題器確認仍能一步步推出唯一答案，否則保留該數字。
3. 啟用前另以完整搜尋確認恰好只有一組解（`countSolutions` = 1）。

| 關卡 | 顯示數字數 | 迴圈內格數 | 需要的推理 |
| --- | --- | --- | --- |
| 1 | 12–14 | 9–14 | 只用局部規則（數字、每點 0／2 條線、不可提早封閉） |
| 2 | 10–12 | 10–16 | 只用局部規則 |
| 3 | 9–11 | 10–16 | 局部規則＋單步假設排除 |

題目、種子、生成器版本與正解與其他遊戲一樣存入輪次結果與匯出；投影端在作答中只收到數字，正解只在小結算才送出。

## 5. 畫面與觸控

- 牆面 640×640 局部設計座標：第 9、10 排（y＝0–128）為狀態列；棋盤在 x＝80–560、y＝144–624（每格 96 px，約 37.5 cm）。
- 觸控命中與畫面繪製使用同一個 `boardRect`；8 個牆面的旋轉沿用既有玩家區轉換，自動測試逐一驗證每面都對到同一條邏輯邊。
- 大廳共用選單：8 款遊戲＋隨機共 9 個選項，但牆面只有 8 區，所以最後一面（P8）左右分成「數迴」與「隨機遊戲」兩半。若後台停用數迴，則恢復每面一個選項。
