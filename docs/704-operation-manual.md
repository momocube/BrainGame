# 704 腦力競賽｜現場操作手冊 v1

版本：v1.1｜日期：2026-11-24｜適用軟體：Windows x64 候選版
本手冊說明工作人員的開場、控場、故障處理與資料匯出。七款遊戲的完整規則見《小遊戲流程與規則》。候選版尚未完成 704 實體場地驗收，首次營運前請依《704現場驗收清單》逐項確認。

## 1. 啟動前準備

1. 開啟 704 投影與觸控設備，讓 Windows 使用延伸桌面。確認投影輸出接在預定遊戲螢幕，實體方向和場館平常使用的顯示設定一致。
2. 若要求 1:1 像素輸出，請在 Windows 顯示設定把遊戲螢幕設為 2688×3840。程式不會自行更改 Windows 解析度；其他解析度會等比例縮放完整畫布，後台會提示目前不是原生解析度。
3. 使用單檔安裝程式「704 腦力競賽-0.1.0 Setup.exe」安裝並啟動。可攜版則須保留並執行整個「704 腦力競賽-win32-x64」資料夾，不可只複製主程式 EXE。若再次開啟程式，新啟動的版本會接手；舊實例會先關閉遊戲伺服器及自己管理的 TouchService，清理完成後退出，再開啟新版本。首次換用支援交接的新版本時，舊版仍開著的話需先正常關閉一次，因舊版不支援交接。控制台上方的「操作手冊」按鈕可隨時開啟本文件。
4. 首次啟動會將主要螢幕指定為工作人員控制台，第一台非主要螢幕指定為遊戲輸出。若實際投影器不是自動選到的那台，從選單「704 腦力競賽 → 螢幕設定…」開啟螢幕設定，使用「辨認這台螢幕」確認，再儲存設定。
5. 確認控制台上方的 TouchService 與遊戲畫面狀態都已連線。啟動器會自動啟動隨包的 TouchService，或重用已通過 704 場域握手的相容服務。等服務自檢結束、互動狀態已驗證啟用，並確認投影畫面已連線與完成繪製；未就緒時「開始 45 分鐘場次」會被拒絕。
6. 按「觸控校正」，確認服務版本、venue 704、互動狀態與離手延遲。依驗收清單逐區觸碰校正。入口粒子區不得出現玩家輸入；若玩家區方向、邊界或出口位置不符，先不要開場，記錄問題及照片／座標。

## 2. 檢查遊戲設定與題目

1. 在待機畫面展開「遊戲設定」，確認要開放的遊戲已啟用。設定變更只會套用到下一場。
2. 若修改過設定，先按「檢查啟用遊戲題目」。檢查會依目前畫面中的設定草稿生成並驗證各啟用遊戲的所有輪次；全七款啟用時應檢查 80 輪。結果只顯示通過輪數或失敗輪次，不顯示答案，也不會自動儲存草稿。
3. 修改設定後，確認題目檢查通過，再按「儲存遊戲設定」。若儲存後又有變更，請重新檢查。固定六選項版面等結構設定不可修改；不要手動改 TouchService venue 或玩家幾何來排除設定錯誤。

## 3. 開始場次與玩家流程

1. 工作人員按「開始 45 分鐘場次」。倒數計時隨即開始並進入大廳；依實際到場順序，在後台按「工作人員代加入下一位」為玩家配置 P1…Pn。玩家長按答題牆不會加入，也不能自行暫停。
2. 八個固定牆面選項區共同組成 704 全場單一遊戲選單；所有玩家共同選一款遊戲或隨機抽選。選擇後介紹顯示在地板中央，玩家由地板共用「確定」或「取消」控制全場流程。玩家加入名單會在離開大廳時鎖定；只有回到大廳後，工作人員才能再加入玩家。1–3 人沿用 4 人版，4 人使用並列題目／答題區，5–8 人的題目顯示於地板。
3. 教學操作說明顯示在牆面，完成教學的按鈕只在地板中央顯示一次。任一玩家長踩約 1 秒並於按鈕範圍內放開，便倒數 3 秒開始；玩家牆面不能各自完成教學。工作人員可按「代玩家完成教學並開始倒數」介入。
4. 小遊戲依規則自行進行各輪，輪後顯示答案、名次與加分 5 秒；一組完成後回大廳繼續選擇下一款。完整操作、錯誤處理與排名方式見《小遊戲流程與規則》。

## 4. 工作人員控場

- 「暫停」會凍結場次與輪次時間並停止接受作答。系統保護性暫停會以「【系統異常】」標示，並回報觸發來源、具體原因及 TouchService／投影就緒狀態；排除原因並確認兩者恢復後，才可由工作人員按「繼續場次」，接著有 3 秒準備倒數。玩家不能自行暫停或繼續。
- 「教學返回大廳」只在教學階段使用；玩家名單與已得分數保留。
- 「重開本輪」只在倒數或作答中使用。原輪作廢，以同難度重新出題；已結算分數保留。
- 「作廢本輪並回大廳」會捨棄目前未結算輪次並返回大廳，已結算分數保留。
- 45 分鐘在大廳、教學或倒數中到時，直接進總結算；遊戲作答中到時，先完成當輪及小結算，不再開始新輪。
- 「立即結束場次」會直接結束場次並進總結算，未完成輪次不會繼續。總結算顯示時按「遊戲結束・返回待機」才會清除目前畫面狀態並開放下一場；已結束場次仍保留在本機紀錄。

## 5. 異常處理

| 狀況 | 處理方式 |
| --- | --- |
| TouchService 未就緒、互動停用或狀態無法驗證 | 不要開場。等待自檢完成並依場館流程確認服務互動狀態；恢復後由工作人員確認可操作再開始。 |
| 遊戲畫面未連線或未完成繪製 | 使用「開啟遊戲畫面」，確認它位於投影螢幕且全畫面正常更新。後台就緒提示通過前不要開始。 |
| 場次中 TouchService／投影異常 | 系統會以「【系統異常】」保護性暫停並回報原因：TouchService 斷線、互動停用／狀態無法驗證，或超過 3 秒未收到服務資料；投影斷線或連線中超過 4 秒沒有畫面繪製回報。依後台顯示的來源與原因恢復服務或投影，確認玩家區與畫面正確，再由工作人員手動繼續；不要反覆重開程式。 |
| 螢幕被拔除，或位置、解析度、縮放、方向改變 | 系統會要求重新確認顯示器配置，必要時先暫停場次。重新指定正確的控制台與遊戲螢幕並確認畫面後再繼續。 |
| 觸點落在錯誤玩家區、畫面顛倒或入口可操作 | 立即暫停，不要讓玩家繼續作答。開啟觸控校正並記錄實體牆面、TouchService face、玩家區及座標；不要在營運中自行更改場域幾何。 |
| 程式意外關閉或主機重啟 | 重新啟動並檢查恢復狀態。已結算輪次與分數會保留，中斷輪依安全規則重試或進總結算；確認名單、輪次和分數後再操作。 |

TouchService 的 venue、觸點校正與互動總開關由場館既有管理流程維護；遊戲不會代替工作人員切換服務狀態。關閉遊戲程式時，啟動器只會停止由本程式自行啟動的 TouchService。

## 6. 場次紀錄與關閉

1. 在後台「場次紀錄與匯出」選擇場次，按「下載 CSV」取得表格資料；按「下載完整 JSON」取得該場的完整保存資料。中斷場次也可匯出目前已保存內容。
2. 每場結束後，將匯出檔移至場館指定的營運資料夾並確認檔案可開啟。場次紀錄先保存在本機，請勿只依賴瀏覽器下載紀錄。
3. 總結算確認完畢後按「遊戲結束・返回待機」，再用程式選單正常結束遊戲。不要在仍有玩家作答時直接關閉主機。
