# 遊戲調整（2026-11-26）

分支：`feature/gameplay-adjustments`，基準：`62659ff`（下載版與取得的 origin/main 相同）。不修改或推送 main。

## 本次六項修改

1. **記憶撲克**：4 張公共牌，16 張記憶牌中選 3 張不同牌；合併 7 張牌後比較全部 21 種五張組合，取最佳牌型。不要求必須使用指定數量的公共牌或自選牌。選滿三張才能確認，到時自動提交，少選不計分。結算顯示最佳五張。
2. **數迴**：棋盤上方增加「↶ 上一步」，依序撤回畫線、打叉、清除操作。每位玩家各自記錄，空紀錄時按鈕灰色，新題／重開題目時清空；完成後不能再撤回。保留同事最新縮小的棋盤位置與大小。
3. **立體拼圖**：題目、六個選項、答案與教學使用前、右側、上三視圖。黃色表示缺口投影，包含被其他方塊遮住的缺口；零件可旋轉但不能鏡像。出題排除旋轉後投影與正解相同的不同零件。
4. **地板倒數**：移除答題時地板右上角倒數。玩家區與題目牆的既有倒數保留，開始前的 3 秒倒數不變。
5. **題數進度**：八款遊戲進行時，玩家區標題顯示 `目前題數/本關總題數`，依各遊戲 rounds 設定。
6. **數字速記**：愛心從小字提示拆成獨立 52px 圖示，實心／空心表示剩餘／失去的生命，保留 128px 狀態區，不侵入作答盤。

## 驗證方式

- `npm test`：完整單元／HTTP／觸控路由回歸測試。
- 本機瀏覽器舞台：確認三視圖數量、題數、地板無倒數、愛心尺寸與手機縮放無頁面溢位。
- 本機 HTTP 滑鼠路由：畫線後按上一步，確認線段復原、按鈕恢復停用。
- 內建瀏覽器可讀取 DOM 與計算樣式，但截圖回傳空白，並曾因繪製心跳逾時觸發既有自動暫停；沒有修改此保護機制，視覺外觀尚未完整驗收。
- 真正場館投影與 TouchService 實體觸控、Electron 安裝包仍需在場地驗收。
- 新場次使用 4+3 撲克規則；既有 3+2 場次規則仍能通過復原驗證，避免更新時中止其他遊戲的進行中場次。
