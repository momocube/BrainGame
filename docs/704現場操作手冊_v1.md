# 704 腦力競賽｜現場操作手冊 v1

版本：v1.15｜日期：2026-11-27｜適用軟體：Windows x64 候選版
本手冊說明工作人員的開場、控場、故障處理與資料匯出。原七款遊戲規則見《小遊戲流程與規則》，第八款見《數迴規則》。候選版尚未完成 704 實體場地驗收，首次營運前請依《704現場驗收清單》逐項確認。

## 1. 啟動前準備

1. 開啟 704 投影與觸控設備，讓 Windows 使用延伸桌面。確認投影輸出接在預定遊戲螢幕，實體方向和場館平常使用的顯示設定一致。
2. 若要求 1:1 像素輸出，請在 Windows 顯示設定把遊戲螢幕設為 2688×3840。程式不會自行更改 Windows 解析度；其他解析度會等比例縮放完整畫布，後台會提示目前不是原生解析度。
3. 使用單檔安裝程式「704 腦力競賽-0.1.0 Setup.exe」安裝並啟動。可攜版則須保留並執行整個「704 腦力競賽-win32-x64」資料夾，不可只複製主程式 EXE。若再次開啟程式，新啟動的版本會接手；舊實例會先關閉遊戲伺服器及自己管理的 TouchService，清理完成後退出，再開啟新版本。首次換用支援交接的新版本時，舊版仍開著的話需先正常關閉一次，因舊版不支援交接。控制台上方的「操作手冊」按鈕可隨時開啟本文件。
4. 首次啟動會將主要螢幕指定為工作人員控制台，第一台非主要螢幕指定為遊戲輸出。若實際投影器不是自動選到的那台，從選單「704 腦力競賽 → 螢幕設定…」開啟螢幕設定，使用「辨認這台螢幕」確認，再儲存設定。
5. 確認控制台上方的 TouchService 與遊戲畫面狀態都已連線。啟動器會自動啟動隨包的 TouchService，或重用已通過 704 場域握手的相容服務。等服務自檢結束、互動狀態已驗證啟用，並確認投影畫面已連線與完成繪製；遊戲畫面未就緒時「開始 45 分鐘場次」會被拒絕；TouchService 未就緒時仍可開場並用滑鼠直接操作正常畫面，實體觸控則等服務就緒才接受輸入。
6. 按「觸控校正」，確認服務版本、venue 704、互動狀態與離手延遲。依驗收清單逐區觸碰校正。入口粒子區不得出現玩家輸入；若玩家區方向、邊界或出口位置不符，先不要開場，記錄問題及照片／座標。

每次開啟程式（包含重新開啟新版 EXE）都從待機開始；上一場已結算成績先保存到歷史場次，不會直接跳到「暫停中」。

## 2. 檢查遊戲設定與題目

待機投影只在地板中央顯示「腦力競賽／光域704」Logo，牆面及地板空間為接近全黑的深藍底色，搭配青綠／金色動態粒子。此時不顯示玩家框、文字、退出按鈕或滑鼠測試提示；點 Logo 不會開始遊戲。後台開始場次後才進入大廳，結束場次並返回待機後會恢復 Logo 與粒子。

1. 在後台待機畫面展開「遊戲設定」，確認要開放的遊戲已啟用。設定變更只會套用到下一場。
2. 若修改過設定，先按「檢查啟用遊戲題目」。檢查會依目前畫面中的設定草稿生成並驗證各啟用遊戲的所有輪次；全八款啟用時應檢查 83 輪。結果只顯示通過輪數或失敗輪次，不顯示答案，也不會自動儲存草稿。
3. 修改設定後，確認題目檢查通過，再按「儲存遊戲設定」。若儲存後又有變更，請重新檢查。固定六選項版面等結構設定不可修改；不要手動改 TouchService venue 或玩家幾何來排除設定錯誤。

## 3. 開始場次與玩家流程

1. 工作人員按「開始 45 分鐘場次」。倒數計時隨即開始並進入大廳，自動加入 P1–P4 四位玩家，可直接選擇遊戲。需要更多玩家時，在大廳按「工作人員代加入下一位」，依序加入 P5–P8，最多八人。玩家長按答題牆不會加入；退出確認可暫停場域。
地板會顯示「已選擇 N 位玩家」與 N 個圈圈。預設顯示四位玩家與四個圈圈，九個遊戲選項可直接操作。選遊戲按鈕移除大型外框，八款 icon 後方有柔和白色光暈。左牆（Wall Left／face 0）第 9、10 排中央顯示一組大型「請選擇遊戲」，其他區域不再重複顯示選單標題。

2. 九個固定牆面選項區共同組成 704 全場單一遊戲選單；八款遊戲均有同尺寸按鈕與專屬 icon，「隨機遊戲」獨立移至數迴右側；所有玩家共同選一款遊戲或隨機抽選。選擇後地板顯示遊戲介紹；其餘八個遊戲選項（含隨機）覆蓋深色蒙版，所選遊戲牆面會暗化底圖並顯示直徑 224px 的圓形「確定／取消」按鈕（較原版放大 40%，點擊外圈同步擴大），玩家在該牆面操作全場流程。取消回大廳時解除蒙版；確認後進入教學。隨機抽選時，以抽中的遊戲顯示確認按鈕。玩家加入名單會在離開大廳時鎖定；只有回到大廳後，工作人員才能再加入玩家。1–3 人沿用 4 人版，4 人使用並列題目／答題區，左牆（Wall Left／face 0）玩家置中，題目在側邊，地板計分與觸控區同步跟隨站位，5–8 人的題目顯示於地板；數迴與踩地雷例外，所有人數均只顯示玩家操作盤，不配置額外牆面題目，地板僅保留進度與成績，結算也不顯示額外解答盤。
3. 教學每面牆共用一組畫面，共四組，不再依玩家分割。踩地雷教學使用放大的向量格盤、48px 數字與向量旗幟，維持三步驟示範。八款遊戲各用三張圖解與三句短提示，約每 3 秒切換一步並循環示範；教學圖與正式題目分開。完成教學的按鈕為地板正中央的共用圓形按鈕。按住時會顯示環形進度與已按秒數；任一玩家持續按住約 1 秒，滿圈即自動進入 3 秒倒數，八款小遊戲牆面與地板的 3、2、1 數字已放大 10 倍，不必放開；短按、移出圓形或滑鼠失去焦點會取消並歸零；玩家牆面不能各自完成教學。工作人員可按「代玩家完成教學並開始倒數」介入。
4. 小遊戲依規則自行進行各輪，輪後顯示答案、名次與加分 5 秒；一組完成後回大廳繼續選擇下一款。完整操作、錯誤處理與排名方式見《小遊戲流程與規則》。

## 4. 工作人員控場

- 「暫停」會凍結場次與輪次時間並停止接受作答。系統保護性暫停會以「【系統異常】」標示，並回報觸發來源、具體原因及 TouchService／投影就緒狀態；確認投影恢復後可由工作人員按「繼續場次」，TouchService 尚未恢復時可改用滑鼠，接著有 3 秒準備倒數。玩家開啟退出確認時也會暫停；取消退出只會恢復原狀態，不能解除工作人員或系統的既有暫停。
- 「回到大廳」位於「場次控制」，可在遊戲介紹、教學、開輪倒數、遊戲進行中、輪次結算、暫停或恢復倒數時使用。玩家名單、已結算名次、累積分數及輪次紀錄均保留；未結算的本輪取消，不額外計分。場次剩餘時間不重設，回大廳後可重新選遊戲。待機、大廳、總結算或場次時間已到時停用；異常暫停時須先確認投影已恢復；TouchService 尚未恢復時可使用滑鼠。
- 「重開本輪」只在倒數或作答中使用。原輪作廢，以同難度重新出題；已結算分數保留。
- 「作廢本輪並回大廳」會捨棄目前未結算輪次並返回大廳，已結算分數保留。
- 45 分鐘在大廳、教學或倒數中到時，直接進總結算；遊戲作答中到時，先完成當輪及小結算，不再開始新輪。
- 「立即結束場次」會直接結束場次並進總結算，未完成輪次不會繼續。總結算顯示時按「遊戲結束・返回待機」才會清除目前畫面狀態並開放下一場；已結束場次仍保留在本機紀錄。

- 「退出遊戲」固定顯示於東小牆（TouchService face 6／Wall Right little），1–8 位玩家位置一致。點擊後全場暗化，暫停場次、倒數、輪次及結算計時並停止作答；再點「確認退出」即可全體回大廳，不需長按。玩家名單、既有名次、累積分數及結算紀錄保留，未結算本輪取消；場次時間不重設。點「取消」則恢復原狀態。支援 TouchService 與滑鼠。
- 遊戲介紹、教學、倒數、遊戲中、輪次結算、暫停及恢復倒數均可使用退出確認；大廳、總結算或場次時間已到時，按鈕保持顯示但停用；待機模式則隱藏，只呈現 Logo 與粒子。
- 數字方格改為 5×5 正方形格盤（25 格），題目與結算盤面等比例置中；數字維持放大並依可用空間縮放，答案範圍為 0–16；數字輸入的「確定」移至牆面第 4–6 排（第 1 排在最下方）。結算表依人數配置欄數、縮放字級並保留底部空間。

投影維持 2688×3840 原生畫布。文字以固定場域尺寸繪製後等比例縮放，避免隨視窗尺寸再次縮小；玩家操作提示改為 24px、計分標籤 26–34px、數字鍵盤 48px，使用明亮高對比文字，按鈕與觸控位置不變。

遊戲中的標題會在每個玩家區上方放大置中，下一排以紅色數字顯示倒數時間；公共牌、記憶、選牌等階段也會同步更新。

踩地雷格內數字使用與數字方格相近的大字比例，改為 48px 粗體，維持原有 8×6 棋盤與觸控位置。

玩家答對後，玩家區大字與地板答題進度顯示「你答對了」，等待其他玩家完成。

### 答錯提示與結算

- 數字方格、數方塊、立體拼圖與地圖定位答錯時，該玩家區會覆蓋低飽和紅色蒙版及大型白字「錯誤」，顯示剩餘鎖答秒數；解除鎖答時自動消失，暫停期間不扣鎖答時間。
- 踩地雷踩中地雷時，同樣顯示約 0.9 秒「錯誤」提示，但仍可立即操作；每顆不同地雷的罰時維持原規則。
- 記憶撲克已選牌以完整青綠色內框與實色底顯示，四邊都位於牌面內，不改變滑鼠／觸控命中區。
- 每輪結算的加分以獨立大字顯示；玩家牆面字級 180px，地板與其他結算表依空間自適應，保留小數與完整數字。第一名金黃、第二名亮藍、第三名銅橘，同名次使用相同顏色；其餘為白色，總結算同樣放大。

## 直接操作第二螢幕

1. 第二螢幕的正常遊戲畫面隨時接受滑鼠左鍵，不需開關、切換測試模式或另開測試畫面。後台「開啟遊戲畫面」在桌面程式中只會帶到原有遊戲視窗。
2. 遊戲畫面完成載入後即可開場，自動加入四位玩家，之後可在大廳由後台增加人數；其他電腦未連接 TouchService 也可操作。後台仍顯示實際 TouchService 狀態。
3. 左鍵直接點擊正常畫面的牆面選單、確認／取消與玩家答案；教學中央按鈕按住約 1 秒即開始。移出按鈕或視窗失去焦點會取消長按。
4. 滑鼠與已就緒的實體觸控同時有效，沿用相同命中與計分規則，互不清除另一來源的長按。暫停、倒數、退出確認與鎖答仍遵守正常遊戲規則。
5. 已連線的 TouchService 中斷仍會暫停，工作人員可確認第二螢幕正常後按「繼續場次」改用滑鼠；投影中斷仍須先恢復。從未連接 TouchService 的滑鼠操作不會因反覆重連而暫停。

## 5. 異常處理

| 狀況 | 處理方式 |
| --- | --- |
| TouchService 未就緒、互動停用或狀態無法驗證 | 實體觸控暫不接受輸入；可直接使用第二螢幕上的滑鼠操作。要使用實體觸控時，等待自檢完成並確認互動狀態。 |
| 遊戲畫面未連線或未完成繪製 | 使用「開啟遊戲畫面」，確認它位於投影螢幕且全畫面正常更新。後台就緒提示通過前不要開始。 |
| 場次中 TouchService／投影異常 | 系統會以「【系統異常】」保護性暫停並回報原因：TouchService 斷線、互動停用／狀態無法驗證，或超過 3 秒未收到服務資料；投影斷線或連線中超過 4 秒沒有畫面繪製回報。依後台顯示的來源與原因恢復服務或投影，確認玩家區與畫面正確，再由工作人員手動繼續；不要反覆重開程式。 |
| 螢幕被拔除，或位置、解析度、縮放、方向改變 | 系統會要求重新確認顯示器配置，必要時先暫停場次。重新指定正確的控制台與遊戲螢幕並確認畫面後再繼續。 |
| 觸點落在錯誤玩家區、畫面顛倒或入口可操作 | 立即暫停，不要讓玩家繼續作答。開啟觸控校正並記錄實體牆面、TouchService face、玩家區及座標；不要在營運中自行更改場域幾何。 |
| 程式意外關閉或主機重啟 | 每次重新開啟均進入 Logo 待機畫面，不自動續玩或顯示上次暫停。上一場已結算輪次與分數保存在歷史場次，未結算輪次不計分；由工作人員開始新的四人場次。 |

TouchService 的 venue、觸點校正與互動總開關由場館既有管理流程維護；遊戲不會代替工作人員切換服務狀態。關閉遊戲程式時，啟動器只會停止由本程式自行啟動的 TouchService。

## 6. 場次紀錄與關閉

1. 在後台「場次紀錄與匯出」選擇場次，按「下載 CSV」取得表格資料；按「下載完整 JSON」取得該場的完整保存資料。中斷場次也可匯出目前已保存內容。
2. 每場結束後，將匯出檔移至場館指定的營運資料夾並確認檔案可開啟。場次紀錄先保存在本機，請勿只依賴瀏覽器下載紀錄。
3. 總結算確認完畢後按「遊戲結束・返回待機」，再用程式選單正常結束遊戲。不要在仍有玩家作答時直接關閉主機。

## 7. 題目辨識更新（2026-11-27）

- 3D 立體拼圖的題目、六個選項、結算答案及教學均使用前、右側、上三視圖。亮藍色表示已有方塊，黃色表示缺口投影（包含被其他方塊遮住的缺口）；零件可旋轉但不能鏡像。結算顯示正確選項的零件三視圖；確定鍵位於選項上方（第 8 排）。
- 記憶撲克公共牌採放大牌面，顯示點數、大花色圖案及中文花色名稱；紅心／方塊為紅色，黑桃／梅花為深色。地板使用大型牌面，較小的牆面題目板會等比例容納四張牌，避免裁切。每輪先單獨公開公共牌 3 秒，再記憶 16 張牌 20 秒；公共牌持續保留，接著蓋牌選牌 10 秒、揭曉倒數 3 秒。新場次使用 4 張公共牌，玩家從 16 張記憶牌選 3 張不同牌；合併 7 張取最佳五張牌型，選滿三張才能確認，少選不計分，結算顯示最佳五張。既有 3+2 場次保留於歷史紀錄，重新啟動後不自動續玩。確定鍵移至牌區上方（第 8 排），已選數量放大 3 倍，並同步更新觸控範圍。

- 3D 數方塊題目與結算三個視角的格線加粗為原本 3 倍（0.135 → 0.405）。數字速記點擊無數字的黑色空格直接略過，不扣心、不重置進度、不觸發閃紅；只有數字順序按錯才扣 1 心並從 1 重來，重點已答過的數字亦屬順序錯誤。教學與規則同步更新。
