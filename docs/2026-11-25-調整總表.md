# 2026-11-25 腦力競賽調整總表

依今天對話與專案變更整理為 39 項；同一功能後續修改以最後確認的需求為準。第九版累積包含今日修改，先前版本記錄見《製作規劃報告.md》。

| 項次 | 分類 | 最終調整內容 |
| --- | --- | --- |
| 1 | 遊戲整合 | 先 fetch，將分支上的第八款「數迴」合併至 main，整合為八款遊戲。 |
| 2 | 電腦測試 | 支援使用滑鼠點擊遊戲介面，沿用觸控命中區域。 |
| 3 | 後台操作 | 新增「回到大廳」，保留已結算名次與累積分數。 |
| 4 | 玩家退出 | 在東小牆固定顯示退出按鈕；場次開始後跨階段保留，無可退出小遊戲時停用。待機只保留 Logo 與背景。 |
| 5 | 退出防呆 | 退出改為點擊後再按「確認退出」，不使用長按；確認畫面暫停全場計時與作答並暗化場域。確認後全體回到大廳、保留已結算名次分數；取消則恢復。 |
| 6 | 教學畫面 | 每面牆共用一組教學，以少量文字搭配三步驟圖片與循環動態示範。 |
| 7 | 教學開始 | 地板正中央圓形按鈕與長按進度環，按滿約一秒立即進入倒數，不需放開。 |
| 8 | 待機 Logo | 後台開始場次前，只在地板中央顯示提供的 Logo。 |
| 9 | 待機背景 | 所有實體牆面及地板使用動態粒子，底色改為接近全黑的深藍。 |
| 10 | 大廳人數 | 地板顯示已選擇玩家數量，並顯示相同數量的圈圈。 |
| 11 | 未選玩家提醒 | 未加入玩家時，選遊戲按鈕覆蓋黑色蒙版與紅色警告；加入玩家後解除。 |
| 12 | 選單尺寸位置 | 數迴按鈕與其他遊戲相同大小；隨機遊戲調整至獨立完整區域。 |
| 13 | 選單圖示 | 八款按鈕加入提供的 icon，移除大型外框，在 icon 後加入白色光暈。 |
| 14 | 大廳文字 | 移除「全場共用選單」，僅在左牆第 9、10 排中央顯示一組大型「請選擇遊戲」。 |
| 15 | 玩家區標示 | 移除玩家區最頂端的 P1 等編號名稱列，計分板仍保留玩家識別。 |
| 16 | 遊戲標題計時 | 每個玩家區的遊戲標題放大置中，下一排顯示紅色倒數數字。 |
| 17 | 開輪倒數 | 每款小遊戲開始前的 3、2、1 放大約十倍。 |
| 18 | 倒數同步裁切 | 地板與牆面倒數同步，增加各實體面的獨立裁切，避免右側牆面數字越界進入地板。 |
| 19 | 結算裁切 | 調整結算區尺寸、列高與自適應字級，處理第一排文字或介面被截掉的情況。 |
| 20 | 數字確認鍵 | 數字輸入的確認鍵上移至實體第 4–6 排範圍。 |
| 21 | 結算分數 | 玩家牆面加分放大至 180px，約原尺寸十倍；表格依人數與位數縮放。前三名加分使用金黃、亮藍、銅橘色。 |
| 22 | 正確回饋 | 答對後的主要狀態文字由「完成」改為「正確」。 |
| 23 | 錯誤回饋 | 數字方格、3D 數方塊、立體拼圖、地圖定位答錯時，顯示低飽和紅色蒙版與大型白字「錯誤」，直到鎖答結束。 |
| 24 | 數字方格 | 地板數字放大三倍；題目改為 5×5，格子保持正方形。 |
| 25 | 3D 數方塊 | 題目與結算三個視角的方塊格線再加粗三倍。 |
| 26 | 立體拼圖題目 | 虛線改為實線，使用藍色實體方塊與黃色缺口格線增加辨識度。 |
| 27 | 立體拼圖答案操作 | 公布答案顯示正確選項的零件及方向；確定鍵上移。 |
| 28 | 記憶撲克公共牌 | 公共牌放大至少十倍，顯示清楚的點數、花色與紅黑區分。 |
| 29 | 記憶撲克流程 | 先公開公共牌，再進入 16 張牌的記憶階段。 |
| 30 | 記憶撲克操作 | 確定鍵上移，已選數量的提示放大三倍。 |
| 31 | 記憶撲克框線 | 選牌框改畫在牌面內側，搭配實色底，修正旋轉後框線被斜向裁切的情況。 |
| 32 | 數字速記盤面 | 記憶時黑底白字；答題時僅用白格遮住未回答的數字位置，其他空位維持黑底。 |
| 33 | 數字速記錯答辨識 | 錯答閃紅降低飽和度；結算公布答案時，曾答錯或未完成的盤面持續顯示低飽和紅底，下一題恢復黑底。 |
| 34 | 數字速記扣心 | 點到沒有數字的黑格不扣心、不重置進度；只有數字順序按錯才扣心並從 1 重來。 |
| 35 | 踩地雷範圍 | 棋盤移除外圍一圈，改成 8×6。 |
| 36 | 踩地雷模式 | 揭露／標記切換移至棋盤上方，使用藍色／黃色背景區分。 |
| 37 | 踩地雷錯誤提示 | 踩雷顯示約 0.9 秒低飽和紅色「錯誤」提示，仍可立即操作，保留原本罰時。 |
| 38 | 數迴及共用題目 | 數迴玩家棋盤縮為原寬高的 70%；數迴與踩地雷移除額外牆面題目及地板題目／解答，只保留玩家盤面、進度與成績。 |
| 39 | 版本命名 | 發行資料夾採用日期與遞增版次後綴，例如本次 `-2026-11-25-9`。 |
