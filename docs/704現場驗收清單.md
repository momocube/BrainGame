## 1. 啟動與雙螢幕

- [ ] Windows 使用延伸桌面；確認主要螢幕與第一台非主要螢幕的實際編號、位置、方向和解析度。
- [ ] 啟動後台與遊戲投影；後台位於主要螢幕，遊戲畫面全螢幕位於第一台非主要螢幕。
- [ ] 遊戲場域使用固定 2688×3840 TouchService 畫布。原生解析度下確認 1:1；不同解析度下確認等比例完整顯示、沒有裁切，且後台提示非原生解析度。
- [ ] 確認程式沒有自行改動 Windows 顯示模式；確認顯示器設定保存後重啟仍指向正確實體螢幕。
- [ ] 正常關閉並重新啟動一次；確認雙視窗位置、TouchService 狀態與投影就緒狀態恢復正確。

## 2. TouchService 與入口保留區

- [ ] 啟動器使用隨包 TouchService，或安全重用已通過 704 venue 握手的服務；沒有重複啟動服務程序。
- [ ] 後台顯示 TouchService v1、venue 704、互動已啟用及協商離手延遲；等待啟動自檢完成後才允許開場。
- [ ] 在 TouchService 管理端停用互動總開關；後台拒絕新場次，場次進行中會暫停。恢復互動後，遊戲仍須由工作人員手動繼續。
- [ ] 確認入口粒子遮罩落在實體出入口，視覺覆蓋完整且不遮蔽可通行區；入口保留區不出現玩家答題區。
- [ ] 由工作人員觸控校正畫面觸碰入口保留區；不得產生玩家輸入，也不得命中相鄰玩家控制區。

## 3. CAVE 方向、玩家區與觸點校正

先用 8 人版確認完整分配：對面長牆 P1–P3、左牆 P4–P5、右牆 P6–P7、入口側外側 P8。P8 必須位於出口保留區外，程式 CAD 幾何間距為 640 px；同時由現場人員確認實際通行寬度沒有被玩家身體或設備擋住。

- [ ] 依序驗收 4、5、6、7、8 人版；玩家依加入順序取得 P1…編號，版型和前往區域提示隨名單更新。
- [ ] 在觸控校正畫面逐區觸碰四角與中央；八個區域各五點都命中正確玩家區，沒有越界、串位或漏點。
- [ ] 每面文字上緣、數字鍵盤、選項、教學、分數、棋盤及數字速記心數均朝向該區玩家，沒有顛倒或鏡像。
- [ ] 核對牆面方向：TouchService face 0 左牆 270°、face 1 下牆 180°、face 3 上牆 0°、face 4 入口側牆 90°。
- [ ] 4 人版逐位核對題目區與答題區並列；5–8 人版核對題目位於地板、玩家題目語意與方向一致。
- [ ] 8 人同時加入並操作；特別確認 P8 觸點、入口遮罩及出口動線互不干涉。
- [ ] 保存每面照片或錄影；標註實體面、TouchService face、玩家區編號及發現的方向／觸點問題。

## 4. 七款遊戲現場操作抽查

每款至少由不同牆面的玩家各操作一次，並核對正確答案、錯誤回饋、鎖定／扣心規則及結算；禁止只以後台 API 操作代替玩家觸控。

- [ ] **踩地雷**：先按安全起點；確認 10×8 棋盤方向、數字可讀、旗幟與翻格觸點正確，踩雷依規則增加 15 秒成績。
- [ ] **數字方格**：依題目輸入並確認格數與答案；抽查錯答後個人鎖定、其他玩家仍可作答。
- [ ] **3D 數方塊**：各玩家看到相同題意；固定視角的柱高皆可辨識，數字鍵盤命中一致。
- [ ] **立體拼圖**：六個選項均可讀、可按；抽查旋轉辨識與錯答鎖定。
- [ ] **記憶撲克**：確認記憶與選牌階段分開、選兩張才提交、可多人選同牌，並能依德州撲克牌型結算。
- [ ] **2D／3D 地圖定位**：確認牆面旋轉不改變地圖方向；位置正確但方向錯誤時判錯，六個選項命中正確。
- [ ] **數字速記**：確認心數位於高處第 9、10 排；答錯扣心後立即從頭重按、不鎖答，第三次錯誤淘汰。
- [ ] 每款至少測一次同批多人觸控；不得串到其他玩家區、重複送出或漏結算。

## 5. 工作人員介入、暫停與異常恢復

- [ ] 工作人員開始 45 分鐘場次；玩家可在大廳加入、選擇或隨機選遊戲並自行控制小遊戲流程。
- [ ] 工作人員可介入教學、暫停、繼續、重開本輪、作廢本輪及結束場次；作廢輪次不入帳，重複結算不重複加分。
- [ ] 暫停後場次與輪次時鐘停止；人工繼續先出現 3 秒準備倒數。
- [ ] 遊戲輸出視窗隱藏或停止繪製超過規則門檻時自動暫停；視窗恢復後仍需工作人員手動繼續。
- [ ] 測試 TouchService 中斷及重新連線；進行中場次暫停、名單與已結算分數保留，服務重新就緒後不自動續玩。
- [ ] 程式重啟後確認回到安全狀態：已結算輪次保留，中斷輪次依規則重試或進總結算，沒有重複給分。
- [ ] 場次到 45 分鐘時，確認大廳／教學／倒數直接進總結算；遊戲中則先完成當輪與小結算，不再開始新輪。
- [ ] 總結算持續顯示，直到工作人員結束場次並返回待機；確認 CSV 與完整 JSON 可匯出。

## 6. 完整營運測試與放行

依 P5 規劃至少完成 **兩場完整 45 分鐘現場測試**，並記錄場次 ID、異常事件、暫停時間、TouchService／投影中斷及匯出檔。每場同時觀察玩家等待時間、投影可讀性、觸點疲勞與入口動線。

- [ ] 第一場完整 45 分鐘測試通過，結束後核對總結算與匯出資料。
- [ ] 第二場完整 45 分鐘測試通過；至少一次演練暫停／恢復與服務重連。
- [ ] 所有上列必測項目通過；失敗項目已修正並重測，沒有未記錄的失敗或資料遺失。
- [ ] 將驗收紀錄、照片／影片、TouchService 日誌及匯出檔保存至專案 `docs/field-results/YYYY-MM-DD/` 對應場次資料夾。

**放行判定：** 雙螢幕、畫面方向、入口安全、所有玩家區觸點、七款操作、暫停／重連，以及兩場完整 45 分鐘測試全部有證據通過後，才能把候選版標示為 704 現場驗收版。
