# 704 現場測試包｜2026/11/26-3｜規則 1.0.19

## 啟動

1. 將整個 ZIP 複製到現場電腦，全部解壓縮到新資料夾。不要覆蓋正在使用的舊版本。
2. 正常關閉舊版後，雙擊 **704-Brain-Game.exe**。保留所有隨附檔案，不能只拿 EXE。
3. 包內已有 Electron 與自包含 TouchService，不需要 npm、Node.js 或另裝 .NET。
4. 在場館使用延伸桌面，從控制台「螢幕設定」確認遊戲輸出。先驗證 TouchService、投影完成繪製與觸控校正，再開始場次。
5. 一般電腦測試：待機時按「開啟滑鼠測試」，確保遊戲視窗可見，再按「開始 45 分鐘場次」並加入玩家。
6. **請結束舊場次後重新開場**，才會使用新版題庫與現有物件拼圖；恢復舊場次仍保留舊題意。

## 本版改動與驗收

### 1. 個人結算與積分
- 上半部顯示本題得分；下半部以「積分」標籤搭配同尺寸、同美術風格的青綠色大數字。
- 積分由加分前的總分跳至新總分，約 1.6 秒完成，支援並列名次的 0.5 分。
- 其他玩家狀態更新不會重新播放計數。未加分時維持原數值。
- 個人結算下半部統一用於積分，取代舊版小字或個人題盤回顧。

### 2. 3D 數方塊
- 三個固定視角的方塊邊線由 0.405 加粗為 1.215，即上一版的三倍。

### 3. 答對回饋
- 「正確」改為「答對了!」，並播放約 2 秒的彩色禮花。
- 禮花侷限於個人區，不遮擋其他玩家，也不攔截觸控。
- 單人或最後答對直接進結算時仍提供回饋；未完成、淘汰不播放。
- 系統偏好減少動態效果時不放禮花，積分直接顯示最終數值。

### 4. 立體拼圖
- 新題目顯示「現有物件」的三視圖，**不是缺口積木**。
- 綠色輪廓合併為整體，不畫單格內線或背景格線；維持 L 型對齊與相同尺度。
- 依完整外框尺寸推理缺少部分，從六個立體零件選出可補回外框的一個；可旋轉、不能鏡像。
- 新題庫同時檢查缺口可由投影推斷及選項唯一性，避免缺口全被遮住而無法作答。

### 5. 2D／3D 地圖（物件三視圖辨識）
- 名稱與 ICON 不變，仍為三視圖選六個立體物件。
- 同題選項共用正面輪廓，改比較後方結構的寬度與高度。
- 有只看正面＋上方仍無法分辨的選項，也有只看正面＋右側無法分辨的選項，必須綜合三視圖。
- 保留圓弧、斜角與階梯等造型，同色、同朝向，不需旋轉。

## 本機驗證

- 完整自動化回歸：218／218 項通過。
- 新拼圖 2,000 題生成驗證通過，並另用獨立旋轉／平移枚舉驗證唯一解。
- 物件辨識題驗證正面相同、上／右各有必要資訊；包含隱線、遮擋與投影一致性測試。
- 以真實引擎快照與正式舞台程式檢查結算大小／顏色、無格線投影與三倍線寬；這是本機測試用畫面，不是現場完整流程驗收。

## 啟動限制與驗收範圍

- 上版測試時，製作電腦的 Smart App Control／應用程式控制政策阻擋未數位簽章 EXE（Code Integrity 事件 3077）。本版仍是未簽章測試包，**不保證能在採用相同政策的電腦直接啟動**。
- 請先由管理人員確認允許的部署方式；需要簽章的環境應使用可信任憑證簽署的版本。不要為了測試關閉安全政策。
- 自動化測試與本機畫面預覽不等於正式場地驗收；實體投影、觸控與完整多人流程仍須現場確認。
- 測試時不要最小化遊戲視窗；畫面長時間未繪製會觸發既有保護性暫停。
- 「操作手冊」可在控制台開啟；其中舊版玩法說明以本文件為準。
- 本次只提供單一可攜 ZIP，不包含重複 Setup、nupkg 安裝／更新封裝。
