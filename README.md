# 704 腦力競賽

本專案所有程式、規則與文件以此儲存庫根目錄為準。

目前階段：大廳改為八個固定牆面區共同組成全場一份遊戲選單；遊戲介紹後，在所選遊戲牆面顯示暗化底圖及圓形確認／取消按鈕，教學完成仍由地板單一共用按鈕操作。踩地雷、數字方格、數字速記等數字格線加粗 3 倍；投影計分板文字放大 3 倍；數字速記答錯時，個人答題盤閃現紅色半透明遮罩。數字答案欄使用 140 px 字級，數字鍵盤有獨立觸控矩形並調整按鈕位置。七款小遊戲與共用流程可執行；場次、判題、計分、TouchService v1 輸入轉接、後台、異常暫停及雙螢幕投播均已實作。玩家由工作人員在後台加入。正式 704 現場投影、雙螢幕位置與觸點校正仍待驗收。

`npm test` 序列模式 122/122 通過，涵蓋七款遊戲、題目生成、45 分鐘場次、玩家版型與觸控方向、入口安全、共用選單、所選遊戲牆面圓形確認／取消、數字速記錯誤閃光、計分板欄數自動配置、TouchService 模擬串接、投影同步、雙螢幕指派及桌面 IPC。Headless Chrome／mock TouchService 已檢查共用選單、遊戲介紹、教學、加大計分板與錯答閃紅畫面。

## Windows EXE 啟動與交付

程式會把第二次開啟視為版本接手：新啟動的 EXE 會請舊實例先關閉遊戲伺服器及由它管理的 TouchService，舊實例完成清理後退出，再由新 EXE 開啟。首次換用支援此交接的新版本時，仍在執行的舊版不認得交接資料，需先正常關閉一次；更新後的版本即可自動接手。
