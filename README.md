## Windows EXE 啟動與交付

程式會把第二次開啟視為版本接手：新啟動的 EXE 會請舊實例先關閉遊戲伺服器及由它管理的 TouchService，舊實例完成清理後退出，再由新 EXE 開啟。首次換用支援此交接的新版本時，仍在執行的舊版不認得交接資料，需先正常關閉一次；更新後的版本即可自動接手。

Windows x64 最新候選包位於 `out/recovery-candidate-2026-11-25-8/`。可攜資料夾內的 `704-Brain-Game.exe` 必須連同整個資料夾使用；候選 EXE 和實體 TouchService 依先前指示不啟動。雙螢幕及 704 現場投影／觸點驗收仍待完成。

後續以 `npm run make:desktop` 產生的版本，總資料夾及可攜程式資料夾統一加上 `-YYYY-MM-DD-版次` 後綴，日期採台灣當日日期。新版命名從第 5 版開始，例如 `out/recovery-candidate-2026-11-25-5/704 腦力競賽-win32-x64-2026-11-25-5/`；版次依 `out/` 既有新格式版本的最大值繼續遞增，跨日不歸零，請保留版本資料夾以維持序號。`BRAIN_GAME_OUTPUT_SLOT` 可指定總資料夾名稱前綴，日期與版次由腳本附加。既有版本名稱保留。
