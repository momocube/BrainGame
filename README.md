## Windows EXE 啟動與交付

程式會把第二次開啟視為版本接手：新啟動的 EXE 會請舊實例先關閉遊戲伺服器及由它管理的 TouchService，舊實例完成清理後退出，再由新 EXE 開啟。首次換用支援此交接的新版本時，仍在執行的舊版不認得交接資料，需先正常關閉一次；更新後的版本即可自動接手。
