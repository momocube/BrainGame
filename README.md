# 704 腦力競賽

本專案所有程式、規則與文件以此儲存庫根目錄為準。

目前階段：玩家選擇或隨機抽選後先顯示遊戲介紹，玩家確認才進教學，取消返回大廳；教學不限時閱讀，任一已加入玩家可完成長按開始倒數。投影 SSE 斷線或靜默時會輪詢伺服器狀態，避免後台已恢復而場域畫面停在舊的暫停畫面。七款小遊戲都有可執行的瀏覽器原型；共用場次流程、題目生成、判題、計分、場域畫面與 TouchService v1 輸入轉接已實作，hello 的 releaseTimeoutMs 也納入驗證，並每秒核對 TouchService /config 的 interactionEnabled，明確停用或狀態無法驗證時禁止開場，場次中自動暫停並要求工作人員恢復，工作人員觸控校正即時顯示協商的離手延遲。場域依玩家人數自動套用企劃書第 2 頁版型：1–3 人暫用 4 人版，4 人每位玩家有並列題目區與答題區，5–8 人題目顯示在地板；玩家由工作人員在後台依到場順序加入並取得 P1…編號，版型與位置提示會即時更新。首次啟動自動將後台放在主要螢幕、遊戲畫面投播到第一台非主要螢幕。投影使用 TouchService 原生 2688×3840 畫布，CAD 場域圖逆旋回服務座標；P8 位於入口側最外段，與出口保留區相隔 640 px。投影頁完成畫面繪製並持續回報後，後台才允許開場；TouchService 狀態失效或投影畫面斷線／連續 4 秒未回報繪製時會以「【系統異常】」保護性暫停；後台回報觸發來源、具體原因及就緒狀態，排除原因後須由工作人員手動恢復。自動測試涵蓋面向方向、觸控來源與出口保留區，704 現場投影及觸點校正仍待驗收。

`npm test` 預設以序列模式執行，117 項通過，涵蓋七款題目與玩家變體的種子重現、全套 80 輪題目生成與答案不變條件預檢、場次生命週期與程序重啟保留場次規則快照與恢復、4–8 人 N−r 配分與版型切換、加入順序與分數保留、TouchService 未就緒或投影尚未繪製時禁止開場、投影停止更新／斷線自動暫停與人工恢復、各版型觸控映射、入口排除、CAD 到 2688×3840 服務畫布方向及 P8 出口距離、自動指定第二螢幕和後台提示元素；另包含模擬 WebSocket 服務串接、自檢中拒絕開場及重新連線測試、TouchService 啟動／解析、TouchService 重連保留玩家名單與已結算分數，以及 sandbox preload 的桌面 IPC bridge 測試。遊戲選擇／隨機抽選含介紹確認與取消流程；玩家加入只由後台操作，玩家端不能暫停或繼續；教學準備的長按若移出控制區、流程階段切換或區外放開即取消。投影狀態事件合併後每秒最多重繪 5 次，避免高頻全畫面重建。德州撲克新增全 52 張牌的 2,598,960 種五張組合分類分布、踢腳比較與多人平手／未完成結算驗證。另以加速虛擬時鐘跨多款遊戲驗證完整 45 分鐘場次、暫停及時間到後的結算流程。規則檔載入會要求七款遊戲設定完整存在，並檢查共用計時、計分與版面結構、各遊戲數字輸入界限、棋盤容量及踩地雷安全起點；損壞的設定在進入遊戲前即拒絕。地圖定位與立體拼圖固定六選項的後台／規則檔驗證也有測試覆蓋；3D 數方塊會檢查每根柱子在固定視角下未受遮擋，並跨難度與種子測試；地圖定位的地板題面採用可測試的 SVG 走廊透視模組，含牆面、地板格線及方向／遠近地標。版型設定在 `config/player-layouts.704.json`，伺服器啟動時會逐一驗證各人數版型的 CAVE 顯示面、TouchService 輸入來源、方向、重疊與入口安全。七款遊戲教學現依規則設定顯示逐步操作、錯誤處理與時間摘要。工作人員可在待機時檢查啟用遊戲的完整題組，檢查結果只回報狀態與失敗輪次，不包含答案或種子，且不會儲存未送出的規則草稿。Electron 啟動器首次啟動會將後台放在主要螢幕、全螢幕遊戲輸出放在第一台非主要螢幕；第二螢幕自動全螢幕顯示固定 2688×3840 場域畫布，依螢幕可用範圍等比例縮放並避免裁切；程式不會更改 Windows 顯示模式，若解析度不同會提示設定為 2688×3840 以取得 1:1 像素輸出。新版自包含 TouchService 由 `scripts/build-touch-service-runtime.ps1` 從設定的乾淨來源複製建置，隨桌面包安裝於 `resources/touch-service/`，不再依賴其他電腦上的絕對來源路徑。啟動器優先啟動隨包服務，既有相容服務可重用，`TOUCH_SERVICE_ROOT` 可明確覆寫；退出時只停止由啟動器建立的服務。Windows x64 最新候選包位於 `out/recovery-candidate-20261124-stage-sync02/`，已核對 85 個 app.asar 項目、自包含 TouchService 來源雜湊，以及 ZIP、Squirrel `.nupkg` 內的程式與服務雜湊。正式 704 現場雙螢幕、投影方向與觸點仍待驗收。歷史場次 CSV／JSON 匯出及營運 JSONL 日誌已完成。總結算由工作人員按「遊戲結束・返回待機」後才開放下一場。第一版不加入限時解題提示。

## Windows EXE 啟動與交付

程式會把第二次開啟視為版本接手：新啟動的 EXE 會請舊實例先關閉遊戲伺服器及由它管理的 TouchService，舊實例完成清理後退出，再由新 EXE 開啟。首次換用支援此交接的新版本時，仍在執行的舊版不認得交接資料，需先正常關閉一次；更新後的版本即可自動接手。

Windows x64 最新候選包位於本機 `out/recovery-candidate-20261124-stage-sync02/`（不納入 Git 版本控制）。可攜資料夾內的 `704-Brain-Game.exe` 必須連同資料夾使用；同目錄另有 Squirrel Setup、ZIP 與 `.nupkg`。完整 `npm test` 117/117 通過，封裝驗證確認 `app.asar` 85 項、自包含 TouchService 與隨包手冊；ZIP／`.nupkg` 內三者的 SHA-256 均與可攜包一致。`app.asar` 為 620,349 bytes（SHA-256 `918425E4C041689CA3A3C035A686C74E5C01DBB77E46EB62597638B888C4675F`）；TouchService.exe 為 35,224,829 bytes（SHA-256 `7BB12617564784EAE0BBE6CAC9456D10424155B7747325124A2AC1E656C1029D`）。可攜 EXE 為 249,906,688 bytes，Setup.exe 為 184,926,208 bytes，ZIP 為 188,224,552 bytes，`.nupkg` 為 184,163,749 bytes。此候選版沒有啟動；雙螢幕及 704 現場投影／觸點驗收仍待完成。
